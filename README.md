# Space UI

<img src="https://www.256arts.com/spaceui/icon_spaceui.png" alt="Space UI icon" width="128" align="right">

Turns your iPhone, iPad, Mac, Apple TV, or Vision Pro into a glowing sci-fi control panel.

There's no real functionality behind the buttons — Space UI generates a complete, self-consistent console interface from a seed: shapes, fonts, colors, sounds, and screen bezel, so it looks like a working starship console rather than doing anything. Run it on several devices around a themed room and they can sync to the same look and events over your local network.

[Download on the App Store](https://apps.apple.com/app/space-ui/id1494402514) · [256arts.com/spaceui](https://www.256arts.com/spaceui/)

## Features

- **A new console every time** — the entire look (shapes, corner style, fonts, colors, sounds, screen bezel) is generated from a seed; regenerate it whenever you want a different console
- **Multiple pages** — lock screen, planet scanner, galaxy map, targeting, shields, power management, coms, and music pages, plus onboard puzzle games (Tic-Tac-Toe, Dots and Boxes, Sudoku, Lights Out) that appear during simulated emergencies
- **Multi-device sync** — devices on the same network share one theme and react together to the same events, so a whole room of screens stays consistent
- **HomeKit console** — control your real lights and outlets from a page in the app, with lights that can flash and tint red during an emergency
- **Nearby Interaction** — devices with a U1 chip show each other's live distance and direction
- **Vision Pro space scene** — an immersive ambient scene with planets, your fleet on patrol, and idle or manual hyperspace jumps
- iPhone, iPad, Mac, Apple TV, and Apple Vision Pro

## Building

Open `Space UI.xcodeproj` in the latest Xcode and run the `Space UI` scheme (or `Space UI (tvOS)` for the Apple TV app). See [`AGENTS.md`](AGENTS.md) for the procedural theme architecture.
